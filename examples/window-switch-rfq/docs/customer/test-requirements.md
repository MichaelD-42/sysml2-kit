# Customer test requirements

The tests the OEM prescribes, as received with the request for quotation. The supplier's system and
acceptance tests implement them; the texts are the customer's.

:::{ctr} Durability per key
:id: CTR-001
:purpose: verification
:method: test
:applies_to: CRS-302

Each key shall be actuated 150 000 times per stage, one third each at -40 °C, +23 °C and +85 °C, at
1 Hz, on 6 samples. Actuation force and function shall be checked every 25 000 cycles.
:::

:::{ctr} Haptic measurement
:id: CTR-002
:purpose: verification
:method: test
:applies_to: CRS-301

Force-travel curves of every key shall be recorded on 10 samples per key module and reported with
the first- and second-stage forces.
:::

:::{ctr} Ingress test
:id: CTR-003
:purpose: verification
:method: test
:applies_to: CRS-503

The switch shall be tested mounted in a series armrest trim, dust and dripping water per IP5K3.
:::

:::{ctr} Initial sample inspection
:id: CTR-004
:purpose: verification
:method: inspection
:applies_to: CRS-505, CRS-506

With the first off-tool samples the supplier shall submit an initial sample inspection report:
dimensions against the drawing, mass and label content.
:::

:::{ctr} Environmental test programme
:id: CTR-005
:purpose: verification
:method: test
:applies_to: CRS-501, CRS-502, CRS-504

The switch shall pass the OEM-ENV-100 programme for interior components, mounting location "door",
on 6 samples, with function checks before, during and after each test and the quiescent current
measured with the bus asleep.
:::
