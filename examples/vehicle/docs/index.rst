Vehicle
=======

Example RFQ project for sysml2-kit: customer requirements (Markdown) are realized by use cases and
satisfied by system requirements; features, functions, logical and physical components realize and
satisfy them (SysML v2), reusing the e-drive platform in ``platform/``. Compliance statements answer
what no architecture element can meet; system and acceptance tests verify, test results close the loop.
