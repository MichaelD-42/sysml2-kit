Acceptance tests
================

.. acctest:: Commute drive
   :id: ATC-001
   :verifies: CRS-001, UC-001

   With five occupants, drive the reference commute route there and back from full charge.

.. acctest:: Trailer loading
   :id: ATC-002
   :verifies: CRS-002, UC-002

   Load the vehicle onto a 2000 kg car trailer and secure it at the four tie-down points.

.. acctest:: Acceleration run
   :id: ATC-003
   :verifies: CRS-003, UC-001

   With the driver only, accelerate from standstill at full pedal; record the time to 100 km/h.
